# Pomodoro Klok

A minimal Pomodoro Klok (timer) web application built with React.

## Running Locally

### Prerequisites

- Node.js 18+
- `pnpm`

### Steps

1. **Install dependencies**:
   ```bash
   pnpm install
   ```

2. **Start development server**:
   ```bash
   pnpm dev
   ```

3. **Open in browser**:
   - Navigate to `http://localhost:3000`
